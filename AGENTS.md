# Repository Instructions

Before planning or changing this repository, read `PROJECT_CONTEXT.md` in full.

Treat `PROJECT_CONTEXT.md` as the source of truth for the product scope,
technology stack, implementation order, acceptance tests, and definition of
done. Preserve completed work, make incremental changes, and do not weaken the
offline-first behavior for convenience.

For every implementation phase:

1. Briefly state the purpose of the phase before coding.
2. Inspect the existing project before modifying it.
3. Keep TypeScript strongly typed and the code suitable for a university mini-project.
4. Run relevant checks after the change.
5. Report how to run and manually test the completed phase.
